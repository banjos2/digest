# Выбор AI API для контрольного этапа

13 сентября 2026 года. По решению владельца проекта первая живая интеграция работает через
OpenRouter. Это единый платёжный и API-контур; конкретные модели можно менять без замены ключа и
моделей данных приложения.

## Требования

- русский редакционный черновик по нескольким источникам;
- естественный английский перевод конкретной RU-редакции;
- строгий JSON по схеме и известные ID доказательств;
- маршрутизация только к endpoint, который поддерживает все переданные параметры;
- запрет сбора данных провайдером и Zero Data Retention для каждого запроса;
- учёт токенов, расчёт стоимости и месячный предел до внешнего вызова;
- возможность сменить модель через конфигурацию.

## Стартовая конфигурация

| Задача | OpenRouter model ID | Цена за 1 млн входных/выходных токенов |
|---|---|---|
| Русский черновик | `openai/gpt-5.4` | $2.50 / $15.00 |
| Английский перевод | `openai/gpt-5-mini` | $0.25 / $2.00 |

Обе модели поддерживают structured outputs. Приложение обращается к OpenRouter через
OpenAI-совместимый Chat Completions API по адресу `https://openrouter.ai/api/v1`. Пакет `openai`
используется только как совместимый Python HTTP-клиент; ключ прямого OpenAI API не нужен.

Запросы содержат `response_format` с JSON Schema и правила маршрутизации
`require_parameters=true`, `data_collection=deny`, `zdr=true`. В AI передаются только
редакционные материалы, данные подписчиков не передаются.

Источники: [OpenRouter Quickstart](https://openrouter.ai/docs/quickstart),
[Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs),
[Provider Routing](https://openrouter.ai/docs/guides/routing/provider-selection),
[GPT-5.4](https://openrouter.ai/openai/gpt-5.4) и
[GPT-5 Mini](https://openrouter.ai/openai/gpt-5-mini).

## Бюджет и журнал

Месячный лимит приложения по умолчанию равен $0. Внешний запрос начнётся только после установки
`OPENROUTER_API_KEY` и настройки бюджета. Перед вызовом резервируется верхняя оценка стоимости;
после ответа сохраняются модель, задача, число токенов, ID ответа и рассчитанная стоимость. Полный
промпт и тексты источников в журнал AI-запросов не записываются.

Цены хранятся в конфигурации отдельно от model ID. При смене модели нужно одновременно обновить
цену, сверив её с каталогом OpenRouter. Иначе локальный бюджетный расчёт будет неточным.

## Контрольный тест

На одном наборе проверяются минимум 30 событий: русские, английские, смешанные, противоречивые,
с одним и несколькими независимыми источниками и отдельная выборка по ИИ. Редактор отмечает
неподдержанные факты, потерянные оговорки, ошибки имён и чисел, естественность языка, ссылки,
время правки и стоимость.

Модель можно заменить после сравнения по критическим ошибкам, медианному времени, стоимости
принятого события и доле карточек без существенной переписи. При стартовых тарифах 5 000 входных
и 500 выходных токенов GPT-5.4 стоят около $0.02 за русский черновик. Фактическая оценка будет
рассчитана из `AIRequest` после контрольного набора.
